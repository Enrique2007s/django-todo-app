Accessibility Guidelines

DoDash is committed to being accessible to everyone. Below are a few tips and notes about accessibility on this site.

  • Keyboard Navigation: All interactive elements can be reached using the Tab key. Use Enter or Space to activate buttons and links.
  • Form Labels: All form inputs include visible labels or hidden labels for screen readers so they are announced correctly.
  • Contrast & Readability: Text and controls use sufficient color contrast; if you have difficulty reading any page, try increasing your browser's zoom or enabling high-contrast mode.
  • ARIA & Semantics: Landmarks and ARIA attributes are used where appropriate to improve screen reader navigation.
  • Focus Indicators: Focused elements show clear outlines to help keyboard users track focus.
  • Reporting Issues: If you encounter an accessibility problem, please leave a comment on the about page with details (page, browser, assistive tech used).
