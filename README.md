# DoDash
Welcome to DoDash! DoDash is a website for people who want to manage their tasks in a more organized manner. This site is targetted to those who struggle remembering what they need to do in certain moments, just like going to the fridge for a nice cold ice cream, but when you finally arrive, you completely forget why you want to the fridge in the first place!

When it comes to keeping track of tasks or repetitive routines, DoDash is the answer of your wishes!

# Features

### Navbar
<img width="1914" height="48" alt="image" src="https://github.com/user-attachments/assets/28adc367-3ee8-48ef-a08c-9e17345f8ac9" />
<img width="1920" height="51" alt="image" src="https://github.com/user-attachments/assets/cf6cc024-b003-437b-ab8f-b3a0c4ad977e" />

In the Navbar you will find that when loggen in and logged out(respectively), there will be different navigation options. This site includes registration! This means that users that are not logged in cannot access the sites main functions like adding boards, tasks, or comments.

This section will allow users to register, log in, view their dashboard, and view the about page. It will let them know how many sections the page has and know where they can explore within the views of the site.

### Dashboard
<img width="1915" height="918" alt="image" src="https://github.com/user-attachments/assets/6b30c390-f7bb-4072-8192-3bbf39b58a5a" />
<img width="1910" height="912" alt="image" src="https://github.com/user-attachments/assets/c5a2660a-42d5-4043-98d2-a7bb719a9cc9" />


In the Dashboard, you will find that when logged in and logged out(respectively), there will be different views. The site does not allow users to add content without being registered. When unregistered, a box in the middle of the screen appears asking you to create a board, and when clicking it, the site will ask the user to register before creating boards. As a logged in user, you will also see the box in the middle of the screen and will be allowed to create boards with a title and a description. Once you have one board, the create button will move to the top right side of the screen.

### Create Your Board
<img width="768" height="543" alt="image" src="https://github.com/user-attachments/assets/bb47099b-487d-4cd6-ade8-4fa5968c2743" />

In this section, the user can add a title and description to the board they wish to create. Once finished, they can click on create board to make the board, or cancel to stop the creation of the board. New boards will appear in the Dashboard.

This section allows users to recognie how to create boards and what necessary information is needed.

### Tasks in Boards
<img width="1359" height="1019" alt="image" src="https://github.com/user-attachments/assets/d750409a-0d2e-455c-8b31-509495c6e02b" />

Inside a board, the user will be able to add as many tasks as they wish, as long as they are under 200 characters long. Furthermore, the user will be able to edit or delete a task they have created.

### Editing Tasks
<img width="729" height="373" alt="image" src="https://github.com/user-attachments/assets/e6d40a6e-dfd2-4341-b98e-1eef7a0bded3" />

When clicking edit task, the user will be directed to the view above. Here, the user will be able to edit the task they previously added and will be able to mark it complete. Once marked complete, the words will have a strikethrough.

This section will allow users to know which tasks they have completed and which are still needed to complete, as well as the ability to edit incorrect grammar or change the task itself.

### Deleting Tasks
<img width="976" height="346" alt="image" src="https://github.com/user-attachments/assets/573efda9-86d7-4190-a183-9d9076dcd065" />

However, when clicking Delete Task, you will be directed to the view above. Here, you can either delete the task, or go back to view the tasks.

This section is important because it allows the user to make a final decision as to delete the task or not.

### About DoDash, the Creator of DoDash, Frequently asked questions, and Comments
<img width="642" height="973" alt="image" src="https://github.com/user-attachments/assets/779b5a56-d2e3-4731-98ff-800bc7726619" />

In this section(about section), all users(logged in or not) will be able to see the content. The frequently asked questions is a button, which when clicked, opens up a modal with 3 commonly asked questions and the accessibility guidelines. Furthermore, in the comments section, only registered users are allowed to comment. Unregistered users cannot comment and can only view the comments other people have left. this is to limit the amount of repetition of suggestions because the user will see someone else has already suggested it. Lastly, users who leave a comment will be able to edit or delete their comment.

This section is important as it will help the users know more about the developer, know more about DoDash, learn about the accessibility guidelines, and be able to suggest to the owner of the site what to implement next.

### Sign out
<img width="595" height="300" alt="image" src="https://github.com/user-attachments/assets/cb6b40fb-8fbb-4446-88b3-9f3dda71e358" />

The sign out section is simple. It allows the user to sign out of the site whenever they want after a confirmation(clicking sign out). The cancel button cancels the action, returning the user to the previous view.

This is an important part of the site because, as probably experienced before, users will not accidentally log out when using the navbar.

### Register
<img width="628" height="682" alt="image" src="https://github.com/user-attachments/assets/50f1c789-5295-40a1-99c1-40721e1d24bc" />

The register section allows users to create an account for the site. An username and password is needed, while the email is only optional as there is no implementation of password recovery or email notifications.

### Log in/Sign in
<img width="600" height="459" alt="image" src="https://github.com/user-attachments/assets/e752cc6f-f2ff-4487-9d56-4471e3dd2d93" />

In this part of the site, users are able to log in with an existing account. In the case they do not have an account already, they can click the "Don't have a account? Sign up" button to create an account.

# Deployment
These are the following steps I took to deploy my project into Heroku
1-) Have the procfile
2-) Connect github repo to Heroku
3-) add necessary code for deployment onto Heroku(and dont forget the config vars!).
4-) Once you have added all necessary code, go to Heroku
5-) Deploy your project!
6-) If there are any errors, check the build logs. They should tell you what is wrong
